# Chess Trainer

A chess app that is fun to play and drills openings and the rest of the early game.

| Folder | What it is |
| --- | --- |
| [prototype/](prototype/README.md) | The web prototype (React, TypeScript), published as a Claude Artifact. It is the source of truth for what the app does. |
| [ios/](ios/README.md) | The native iOS app (SwiftUI), ported from the prototype. |
| [spec/](spec/) | The golden cases and constants, generated from the prototype's code. Both apps are tested against them. |
| [docs/](docs/) | The behavior spec ([docs/spec](docs/spec/README.md)), the port plan ([docs/native-port](docs/native-port/plan.md)) and [Autopilot's intent](docs/autopilot.md). |
